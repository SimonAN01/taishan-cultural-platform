静态页面使用HTTP策略，无需为这次采集启动交互浏览器。不会向爬虫发送项目的大模型密钥，也不需要额外付费API。

运行命令：

```sh
cd /Users/meilingz/Desktop/37aic/taishan
.crawl-venv/bin/python scripts/collect_images.py --limit 1000 --max-new 100
```

`--limit`限制清单总数，`--max-new`限制本批新增下载尝试。重跑保留既有清单和已保存照片，逐张原子更新JSON及CSV；不会把重跑的已有文件算作新增。下载端429按Retry-After等待，连续限流后停止并保留进度。

输出：`data/image_library/images/`为照片，`dataset_manifest.csv`与`manifest.json`为来源和许可台账，`summary.json`为真实计数，`crawl4ai_seed.json`记录最新页面抓取状态与时间，`runtime/crawl4ai-run-20261014.log`为本轮日志。
