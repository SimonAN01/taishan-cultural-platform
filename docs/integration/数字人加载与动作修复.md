# 数字人加载、口型与动作修复（2026-10-15）

部署版本：1.4.1；入口：https://118.89.176.236/experience/#agent 。

## 查到的原因

- 原 `public/models/princess-agent.glb` 为 10,677,568 字节，包含约 5.57 MB 的 2048² PNG 贴图，以及未压缩几何。一次公网下载耗时 29.767 秒。加载器建立画布时用 `replaceChildren` 提前移除了加载提示；立绘默认不透明度仅 0.12，因此看起来像卡在透明人物上。
- 发起问答不等待模型加载，TTS 可能在三维就绪前播放完毕；原口型还乘了 0.7 的幅度系数。静态立绘不具备三维口型。
- 原点头峰值约 6.4°，作揖躯干约 6.3°，远望约 9.2°。一次性动作和待机动画同时占据相同骨骼轨道，正常混合又会压低动作幅度。
- 人物区域使用 `overflow:hidden`，绝对定位子元素溢出后，浏览器聚焦按钮会移动这个隐藏滚动容器，导致人物和标题上移。

## 实施

- 保留原始 GLB，新建 `public/models/princess-agent-web-v2.glb`，1,005,188 字节，减少约 90.6%。使用现有 glTF Transform 4.5.1 工具：1024² WebP 贴图、去重、动画重采样、量化及 Meshopt 压缩，未执行减面。保留皮肤绑定和真实口部形变目标。
- 浏览器使用随 Three.js 提供的本地 Meshopt 解码器；CSP 仅增加所需的 `wasm-unsafe-eval`，未允许任意 JavaScript eval 或第三方脚本。带版本模型文件增加一年不可变缓存，直接访问问山优先预加载。
- 保留真实下载进度，立绘清晰显示；失败提供重试。模型就绪前禁用动作按钮。减少动效偏好不再禁用整个人物及口型。
- TTS 下载和模型下载并行，实际播放等待模型就绪；取消后不再播放迟到的音频。缓存最近一段音频供重听。音量分析驱动口型，加大开合；暂停/结束时闭嘴。
- 点头约 20°；作揖躯干约 25°、头约 12°；远望约 30°。一次性动作退出其他姿态，用动画完成事件恢复待机或讲话。自动表情不占用手动口型轨道。
- 人物区域改为 `overflow:clip`，修正聚焦导致的上滚；手机短舞台改用上半身镜头，让嘴部更易看清。问山打开期间暂停背后地图的绘制。

## 验证与边界

- 同一环境公网新模型下载 2.408 秒（旧文件 29.767 秒）；浏览器首次模型就绪 3.806 秒，后续缓存加载观测 0.138 秒。均为单次观测，不代表所有网络或整个网站的加载时间。
- 前端 16 项测试通过；后端 27 项执行、26 项通过、1 项因本地缺少 CLIP 权重跳过。新增测试解码真实压缩资产，检查动作角度、真实口部顶点位移、首次语音等待、重听复用及取消后不播放。
- glTF 验证器：0 个错误。两个皮肤网格非根节点警告继承原模型结构；验证器不支持 Meshopt 扩展的静态校验，因此另外使用实际解码器运行了上述几何、骨骼与形变检查。
- 公网实际音频播放时已截图确认张口；远望和作揖均记录了实际动作画面，人物区域不再上滚。
- 当前模型只有 Root、Torso、Head 三个骨骼。作揖是现有持物姿势下的躬身，不能单独抬手、抱拳或活动手指。语音口型按实际音量开合，尚非逐音素口型。未使用真实麦克风硬件验证识别。
- 原始文件不改动；压缩命令（开发工具已存在，无需部署到服务器）：

