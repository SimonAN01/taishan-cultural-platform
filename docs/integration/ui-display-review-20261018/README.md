# Word UI 展示精修与发布核对

设计依据为用户提供的 `UI设计图.docx`，涵盖 30 个设计编号。此记录为地图、路线、手札修正之后的继续精修；此前记录保留作为历史版本。

## 本轮结果

- 地图采用一整幅桌面/手机底图，去除拼贴断层；画布最小缩放覆盖窗口，地标与画面同坐标变换。问山按钮文字与头像在同一布局中。
- 路线选择页的标题、四条路线、说明、标签、选择框、地图浮签及操作按钮为真实 HTML/SVG。一次仅选中一条路线。实际交通方式、路线节点及开始游历仍连接原有行为。
- 游历手札的标题、上次游历、记录及空状态按真实内容高度排布；底图和独立人物不再含旧卡片文字。记录与收藏使用原有 API。
- 山水图集的标题、筛选和卡片说明为真实文字；保留原稿的五图布局。手机“前往景点”定位在卡片内部。大图翻页、缩放、失败重试可用。
- 石刻文博的导航、切换标签、说明和缩略图选择为真实控件。清除背景上的旧菜单、旧缩放条及旧注释；正文滚动可达，操作文字不会覆盖图片中的旧控件。
- 文化学习页重建章节、导读、相关文化卡和练习区；单选、解释与下一章可操作。此导读练习不伪造完成记录，正式五章进度仍走原有记录组件。
- 游历回顾页以真实探索数量、印章状态、记忆卡和操作按钮渲染。清除旧标题、旧固定数量、卡片边缘残字及重复选择框。

图集五条说明另已逐字对照 Word，改回“云上天门，直通岱顶”“云涌成海，山峦浮沉”“千年古道，万丈雄心”“苍松迎客，岁月长青”“山泉清冷，石上听声”。

## 清晰度和保真边界

主要界面文字与控件独立渲染，避免整张截图放大时文字一起变糊。Word 中的小幅插画本身仍有分辨率上限；标题使用本地 OFL 字体 Ma Shan Zheng，未提供的原字体无法据此证明完全相同。

清理背景时使用内置 image_gen 对原图去除 UI 并补全遮挡山景，保持构图、主体和色调。补全区域属于生成修复，不是 Word 原始高清素材。原来的场景、识景及状态提示中仍有部分位图式设计元素。本轮的“覆盖 30 图”指页面和状态都已检查，不代表所有元素均已原生重建或逐像素零差异。
