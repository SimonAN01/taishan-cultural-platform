# 识景拒识修复 · 1.7.3

2026-10-17。根据用户反馈的亭子素材、“五岳独尊”素材图及岱庙天贶殿实景截图，检查云端识景链路并修复；无需本地训练或 GPU。

## 原因与修复

- 岱庙曾有 `vision_enabled=false`，虽有文化场景，云端候选目录仍排除了它。现已启用，补充天贶殿匾额、建筑特征和关联文化内容。对照范围由 16 处增为 17 处；彩石溪和后石坞仍未开放自动识景，页面明确展示范围。
- 玉皇顶条目没有“五岳独尊石刻”的资料。现依据景区官方[题刻资料](https://tsgw.taian.gov.cn/art/2023/4/13/art_322517_1472.html)及石刻索引，补充子地标与玉皇顶周边导览的关联；不把石刻、玉皇庙本体与大观峰《纪泰山铭》混为一处。
- 旧提示词一概拒绝截图与人物。现在分析画面中的真实地标依据；带游客或截图外框不直接拒识。水印、插画或合成效果也不独自构成拒识理由，可识别明确呈现的题刻，但不证明拍摄位置。
- 补充子地标题字逐字输出及后端校验，避免因空间相邻而追加未出现在画面里的地标。回归中曾发现大观峰照片被额外列为“五岳独尊”，已加入“无可见题字则丢弃该子地标”的检查与测试；仍不代表模型已达到无误识别。
- 未知结果返回画面内容、无法定位原因与下一步建议；旧主站与沉浸前端都展示。云端失败仍返回 503，不伪装成分析成功。
- 透明素材缩放后合成白底再上传，避免直接丢弃透明通道导致背景错误。
- 通用亭子素材没有题刻、环境或独特标志时仍返回未知，不靠外形强行归属。

- 前端 29 项测试通过，构建通过；后端 36 项执行，35 项通过，1 项因可选 CLIP 权重未安装跳过。

- 用户提供的“五岳独尊”图与岱庙图已通过真实云 API 返回对应子地标；亭子素材与纯色图保持未知，附解释。见 [云端实测](vision-fix-20261017/production-final.json)。这些是少量功能回归样本，不是独立准确率评测。
- 桌面真实上传岱庙原图、返回天贶殿、确认后进入岱庙文化详情；手机宽度 390px 下正文和文档均无横向溢出，结果按钮可见。

- 第一次本地云端调用曾遇到一次 503，后续直连与线上调用完成；不能据此承诺第三方服务永不中断。
