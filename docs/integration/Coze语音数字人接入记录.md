# Coze 语音数字人接入

日期：2026-10-15。服务版本：1.4.0。

## 实际链路

用户点击语音提问 → 浏览器 SpeechRecognition 将麦克风语音转成文字 → `/api/agent/chat` → 后端向 Coze `/stream_run` 发送请求并拼接已完成的 SSE answer → 校验本轮文化引用 → 返回回答文本 → `/api/speech/tts` → Microsoft 晓晓 TTS MP3 → HTMLAudioElement 播放 → Web Audio 分析真实音量 → 3D 模型 jawOpen / mouthRound。

数字人口型为音量驱动，不是音素级口型。设备语音降级使用真实语音边界事件，未伪造口型时间轴。

## Coze 契约

使用用户提供的部署地址 `https://7szbsmhhq8.coze.site/stream_run`，Token 仅保存在本机和服务器600权限的环境文件中。前端只有同源 API 地址。模型名称显示为“Coze 智能体”，不猜测该智能体内部使用的基础模型。

已实测此部署不要求传 project_id。请求体结构为：

```json
{"type":"query","session_id":"每个匿名会话与清空版本对应的散列值","content":{"query":{"prompt":[{"type":"text","content":{"text":"当前景点上下文、文化资料与游客问题"}}]}}}
```

`/task/{task_id}` 是异步任务查询接口；本系统使用同步流式调用，不需要预先生成 task_id。官方说明：[通过 API 调用智能体](https://docs.coze.cn/dev_how_to_guides_qeesmmos)。

- 仅拼接 answer 事件，不向客户端转发 thinking、工具调用、鉴权头或上游错误详情。
- 需要成功的 message_end；中断、错误、空回答、不合法引用均不能作为成功回答。
- session_id 由匿名会话和 revision 散列生成。清空后更换上游会话，避免读取之前的上下文；这不代表已删除 Coze 平台自身保存的历史。
- 保留实时票价/开放信息核验限制。Coze 失败时明确返回已有文化资料，不冒充已生成。
- 照片识景仍采用原 DeepSeek 云端图像理解配置，与 Coze 文本问山分开配置。

## 语音和播放

- 麦克风需用户点击授权。关闭数字人、重新提问时停止识别和播放，避免旧音频/旧请求覆盖新状态。
- 可查看转写、关闭自动朗读、停止等待、重试、暂停/继续播放、再听一遍、改用设备朗读。
- 不支持浏览器语音识别、权限拒绝、未检测到麦克风、无语音、语音服务网络错误有各自提示。
- TTS 文本上限1500字；请求有超时、并发和频率限制；音频仅通过响应返回，不持久化保存。
- 公网 HTTP 地址保留文字与朗读功能，麦克风入口引导使用 HTTPS。
