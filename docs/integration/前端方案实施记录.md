# 前端方案 V1.0 实施记录

日期：2026-10-15。实现位置：`/experience/`。沿用 `codex/taishan-integration` 分支。

## 参考与取舍

已读取用户提供的《前端方案.docx》全文，解压《前端界面参考.zip》的 HTML 概念原型与 welcome/map/agent 三张 800px 宽参考图。提取文件保留在仓库外 `../前端参考提取/`。以文档指定的 1440×900、390×844 为主要验收画布。参考 HTML 的示例回答、alert 和静态截图不进入生产功能。

保留欢迎画卷、分层山水、57张用户图片及3D碧霞仙子；采用宣纸底色 #F3EEE2、朱砂 #903C30、石绿 #70837B。新增文化页面使用既有原生 ES 模块、同源 API，不引入第二套框架。标题以本机宋体/衬线回退，功能按钮使用系统无衬线；不同操作系统的字形会有差异。未生成新图片、未引入临时图片占位。

## 页面与交互

- 欢迎：修正“启卷如山”为“启卷入山”，增加跳过动画；文化接口不再阻塞首屏绘制。
- 全景：0.8–2.5倍缩放、鼠标拖拽、触点平移/双指缩放实现、键盘平移、路线图层开关、16景点搜索。整张地图与热点同层变换。内容页关闭后保留地图位置和缩放。
- 景点：同一套界面展示实景图集、照片作者/许可/来源、历史、诗词、景观概述，以及带 spot_id 的问山。缺少独立诗词、建筑细节和实景照片时明确说明；不生成虚构资料。
- 路线：四线比较、主线及支线、乘车/索道说明。天外村徒步与索道分支使用不同的真实节点序列。地图统一采用后端顺序，只绘制已有画境坐标的主要节点，非地理导航。
- 历史：五个时代分组，包含七条已有事件、关联景点及出处。左右键、Home/End 可切换。
- 诗词：三首完整诗，点击诗句查看对应释义，可切换赏析；朗诵按实际 onstart/onend 高亮当前句，不使用估算计时。尚未录入注释的诗句明确提示。
- 识景：本地格式/8MB检查、预览、请求中、取消等待、超时、失败、未知/候选和人工确认；沿用真实云端模型，确认后进入对应景点。FormData 不手动设置 Content-Type。
- 问山：真实回答标注 AI 生成、来源、最近20条会话记录、停止等待、重试、单独清空对话。清空不删除足迹及收藏，服务器版本号防止在途回复恢复已清空记录。
- 手机：文化内容为底部展开面板，七个导航入口直接可见；内容区单独滚动，地图工具与数字人入口分开。

## API 变化

新增 `DELETE /api/agent/history`：清空当前匿名会话对话并更新 revision，不清理他人会话、足迹、收藏或故事进度。其余功能复用 `/api/catalog`、`/api/journey/visit`、`/api/agent/chat`、`/api/agent/history`、`/api/vision/recognize`、`/api/vision/predictions/{id}/confirm`。

方案提到的 Coze 未提供配置，本次继续使用已授权的 DeepSeek 服务，不标记 Coze 已接入。

## 验证

- `npm run build` 成功；当前主脚本含 Three.js，为约 740.28kB（gzip 209.04kB），仍有分块体积提示。
- `npm test`：14项通过，包括 multipart 请求头与取消信号检查。
- 后端 unittest：21项通过，1项可选本地 CLIP 权重测试跳过。新增清空对话保留足迹/收藏及隔离他人会话的回归测试。
- 真实浏览器：经石峪图片上传 → DeepSeek候选 → 人工确认 → 经石峪资料 → 带当前景点的问山 → 带来源回答 → 会话记录。
- 浏览器检查：朝代键盘导航、天外村索道分支排除十八盘、诗句注释、朗诵实际起播与停止、搜索、放大、关闭内容页后保留120%缩放、路线图层开关。
- 截图：1440×900历史页、1900×1000宽屏、1280×800路线首屏及下半页、390×844诗词上下区、320×740窄屏导航与路线。另有导航组件裁剪。详见 `screenshots/frontend-spec/`。窄屏内容容器没有横向溢出。
- 本机浏览器未见控制台错误。不把浏览器视口模拟等同于 iOS/Android 真机测试；双指触控、Safari/Android语音兼容性、正式录屏及真实用户性能数据仍待后续验收。

## 仍待补充
