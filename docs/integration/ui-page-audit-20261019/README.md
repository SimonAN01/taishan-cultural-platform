# 逐页功能修复 · 2026-10-19

保留 Word 设计稿确定的五个主导航与已接受的页面结构。本轮处理阅读位置、错误恢复、图文对应和真实记录，未增加装饰模块或新的演示入口。

## 已修复

| 区域 | 复现问题 | 修改 |
| --- | --- | --- |
| 游山 / 景点 | 从读山打开景点文化，误入上一次的景点 | 未指定景点时统一打开 19 处景点目录；指定景点进入相应详情 |
| 历史长卷 | 第一条秦代资料被示例文案覆盖，日期被朝代名替换 | 展示原始记录和日期；增加上一段；读到末段后停止，避免意外循环 |
| 诗词 | 整页 `data-poem` 误绑定为打开诗词按钮，子控件点击后重新打开首联 | 仅绑定真正的诗词按钮；选句及定位只匹配诗句按钮 |
| 继续阅读 | 选句、赏析方式变化后，继续阅读仍保存较早的位置 | 在更新地址时同步保存当前阅读位置 |
| 山水图集 | 实景分类刷新后丢失；方向键同时触发滚动 | 保存分类；左右键只切图并保留系统组合键 |
| 石刻文博 | 条目、照片、阅读方式刷新后重置；原图被裁切；手机只有很小的下拉箭头 | 地址保留条目、照片与方式；完整显示原图；明确的“切换条目”按钮；键盘切换标签 |
| 手札 | 页签刷新后重置到足迹 | 保存当前页签；保留左右、Home、End 操作 |
| 山境 | “下一处”即使保存失败仍翻页 | 保存成功才继续；失败保持当前主题并允许重试；避免重复提交 |
| 朗读 | 请求失败后停止按钮仍表示可用 | 根据实际播放器状态恢复按钮；停止后迟到请求不会创建播放器 |
| 错误提示 / 图片 | 网络提示混有开发命令；部分红门文案、相关图与正式资料不一致 | 使用面向游客的重试提示；红门简介和相关缩略图采用已收录资料 |

数字人继续使用原有真实 GLB 模型；桌面右侧、手机独立折叠区的布局保留。
