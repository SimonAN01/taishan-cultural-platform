## 修复与精简

旧移动样式隐藏了数字人按钮，并仅在面板已展开时显示按钮，造成用户无法打开。现在按钮始终可见，带展开状态与关联面板。桌面首次进入默认展开，手机默认收起；模型加载失败时保留立绘和重试入口。窄屏模型镜头按纵横比调整，避免侧边栏裁切人物。

景点讲解卡、故事问题和资料入口跟随当前景点，不再统一指向红门。“正在探索”与原稿一致，不暗示语音正在播放。

保留五个主导航和原有页面层次，精简以下内容：

- 地图重复的数字人悬浮入口、装饰雾层及无正式资料的三个标记；19 个正式景点仍可从目录进入。
- 景点搜索的第二层预览，地图标记、搜索名称和目标按钮统一进入同一景点资料页。
- 图集中的内部建模素材、背景板、人物切片；只保留五幅画境和已收录的实景照片。
- 路线中虚构的耗时、数字/现实模式和任意连线；保留真实路线、站点顺序、交通方式、来源及选用操作。
- 重复的研学示例与模拟勾选题，直接使用正式的五章节学习与答题流程。
- 没有对应景点依据的通用配图，以及文博中混入的画境素材。无可靠图片的景点采用文字布局。
- 设置中重复的入口与未完成的索道演示入口。核心问山数字人保留。
