# 交互、方向键与手机按钮修复 · 2026-10-18

本次针对用户发现的“控件像截图、点了没有实际作用”、红门放大断层、山境标题重叠进行修复，并为地图、索道、天街和空间画境接入方向键及手机按钮。生产入口：[腾讯云体验页](https://118.89.176.236/experience/?ui=20261018-controls-v4b#map)。发布结果以同目录 `deployment.json`、`live-checks.json` 为准。

## 操作对应

| 页面 | 键盘 | 手机或鼠标 |
| --- | --- | --- |
| 游山地图 | ↑↓←→ 平移，＋／－缩放 | “方向控制”展开四向按钮；可拖动、双指缩放；原有缩放与复位按钮保留 |
| 云间索道 | 点击画面后，↑前进、↓后退、←→转视角 | 同名方向按钮；暂停／继续、进度条拖动、复位视角、环境声开关 |
| 天街沿街而行 | 点击画面后，↑↓或 W/S 行走，←→转向，A/D 横移 | 前进、后退、左转、右转、复位、退出；可拖动画面看向不同方向 |
| 三卷空间画境 | 点击画面后，←→转视角，↑↓拉近拉远 | 左看、右看、拉近、拉远、复位、依次导读 |

地图不抢占输入框里的方向键，也不处理 Ctrl/Alt/Command 组合键。小屏方向面板展开后位于搜索框上方，不覆盖搜索、缩放和底部导航。地图、索道、天街到边界时，对应按钮置灰；手机按钮与键盘调用相同控制逻辑。离开天街会销毁渲染器与事件状态，避免在别的页面继续运行。

## 实际修复

- 索道改为默认展示真实 WebGL 车厢、缆线与支架。车厢沿同一条轨迹运动；暂停保留位置，继续从当前位置出发，进度条可以定位，抵达终点后可重新乘坐。环境声由 WebAudio 合成风声与低频机械声，开关会实际启动／暂停音频上下文。加载失败显示重试并禁用未就绪控件。公网冷加载曾因较慢下载超过原 45 秒阈值；阈值已改为 90 秒，保留真实下载进度和失败反馈。内置浏览器已实际验证模型载入及暂停／前进。
- 天街“沿街而行”进入可行走的简化三维街道：相机坐标、朝向、石板透视和两侧建筑随操作改变。旧的只替换背景操作被移除。
- 红门背景改用一张连续绘画，观察题字时整张画一起变换。底部重复的截图背景被移除，导览卡和观察面板改用原生文字与按钮。
- 山境目录改用无文字的插画裁片与独立标题、进度、入口，去掉“新标题盖旧标题”的白色贴片。
- 山境阅读页脱离旧截图覆盖布局，恢复正常排版。此前“记录已读”被裁成不可点击区域，现已能通过正常点击保存；修复根节点 `data-scene` 与目录点击处理的冲突。深层阅读页的主导航保持“山境”选中。
- 文博目录切换会更换实际资料和图片；原貌／释文／听讲解切换真实内容，缩略图数量来自实际条目。未收录的完整碑文、测绘和高清实景不编造。
- 图集“四时”依据已有标题的季节信息筛选，空分类有明确反馈。导读自测明确标注不计进度，正式五章学习默认展开并通过服务器核验保存。
- 旧的 `http://118.89.176.236:8037` 入口通过外部应用脚本转到同主机 HTTPS，保留路径、查询参数和锚点，使摄像头／麦克风具备安全上下文。后端、数据库结构和服务器服务配置未修改。

## 素材与边界

索道车厢复用现有 GLB；以临时 CLI 优化为 1.61 MB，原 11.21 MB 模型保留，未简化几何，未修改依赖清单：

```sh
npx --yes @gltf-transform/cli optimize public/models/taohuayuan-cable-car.glb public/models/cable-car-optimized.glb --compress meshopt --texture-compress webp --texture-size 1024 --simplify false
```

山景仍由已有插画分层组成。天街是用于交互的简化三维演绎，岱庙、彩石溪、后石坞仍是分层空间画境，均不是实地测绘或完整建筑数字孪生。真实精细 GLB 仍待建模交付。

红门清洁画稿通过内置 image_gen 编辑，源文件保存在 `../ui-clarity-20261018/sources/visit-hongmen-desktop-clean-v2.png` 与 `visit-hongmen-mobile-clean-v2.png`。编辑要求为：保留红门建筑、牌匾、松树、石狮、石阶和山景的画风与构图；去除网页导航、导览卡、人物头像、发光圆环、光点和所有按钮；将遮挡处补成连续的台阶及山水，不添加界面或水平拼接条。桌面和竖屏分别编辑。这些是补绘素材，不是 Word 中未压缩的高清原稿，也无法承诺与被遮挡区域逐像素相同。

`scripts/refine-native-ui-assets.py` 可从保留源文件生成两张红门无 UI 背景和三张山境无标题裁片；结果记录在原清晰度素材清单中。Word 本身压缩的插画不能仅靠 CSS 恢复原始细节。本次已将上述标题、按钮和阅读控件改成清晰的网页文字。

摄像头／麦克风的实际设备权限、录音质量仍需在用户手机上允许权限后验证；自动化的 ASR 状态截图不代表真实设备录音通过。
