## 本次修正

| 问题 | 处理 |
| --- | --- |
| 天外村索道方案刷新后退回红门 | 将路线和交通方式写入网址并恢复；索道分支仍不经过十八盘 |
| 朝代、诗词、景点标签和照片选择刷新/回退丢失 | 统一编码与恢复内容选择，异常参数回到合法状态 |
| 问山面板和网址不一致，浏览器回退时面板可能留在上层 | 打开问山记录景点上下文，关闭与回退同步界面，恢复原景点标签 |
| 南天门 API 编号与界面编号不一致，欢迎语和推荐问题失去当前景点 | 统一别名，并支持目录中没有独立画境的景点名称 |
| 五岳独尊讲解可能被映射为玉皇顶 | 问山保留实际点击对象；无独立 API 节点时携带真实名称查询，避免伪造景点编号 |
| 切换标签/交通方式时跳到顶部、键盘焦点丢失 | 局部切换保留内容滚动位置，并将焦点留在所选控件 |
| 实景照片在详情中裁切，无法查看全部细节 | 增加完整大图、关闭/ESC 与原图署名来源，支持手机 |
| 诗词朗诵未起播时按钮可能长期停在准备中 | 保留当前语音对象，增加 7 秒起播恢复提示；按真实起播逐句高亮，切换/关闭时取消 |
| 完整导览同一页面切换诗词/景点仍可能朗读上一项 | 切换阅读对象时停止旧朗读 |
| 更换无效图片后遗留旧文件名/预览，隐藏图片样式被覆盖 | 清理旧 URL、文件名、预览和结果；明确隐藏元素不占位 |
| 音频设备恢复后可能重新播放已取消的音频 | 恢复后再次核对请求版本；音频分析失败也不阻断文字功能 |
| 代理返回 HTML 错误时提示无法解析 | 将 413、429、502、503 转为可理解的大小、频率、服务错误 |
| 文化弹层完全覆盖地图时背景仍执行 WebGL 渲染 | 弹层打开期间跳过背景绘制，关闭后继续；未声称测得帧率提升 |

## 已验证的能力与限度

- 内容目录：16 个景点、4 条路线、7 条历史、3 首诗、3 项文博、25 条知识资料；15 个景点有实景照片，总计 20 张，东御道尚缺已核对实景。
- 空白图真实云端调用：HTTP 200、unknown、空候选，2.33 秒；经石峪照片：HTTP 200、经石峪候选与可见摩崖刻字依据，7.12 秒。仅为两个样例，不代表识别准确率；仍要求人工确认。
- 前端 23 项测试通过，含真实压缩骨架、30 手指变形、远望转轴、回答不自动做动作、内容网址恢复、音频取消竞态、代理错误等。
- 后端 27 项执行，26 项通过，1 项可选 CLIP 权重测试跳过。匿名会话隔离、收藏/足迹、清除并发、章节顺序及访问条件、问答引用、识别确认和 TTS 契约有自动检查；不将这些检查当成真实模型准确率。
- 桌面浏览器已复现旧版路线刷新问题，并在预览验证天外村索道刷新、唐宋筛选刷新、南天门诗词标签刷新、景点→问山→回退、原图放大、诗词实际起播/停止。
