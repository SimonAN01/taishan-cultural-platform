## 已完成的真实功能融合

1. 问答从 `setTimeout` 后固定关键词回答，改为请求同源 `/api/agent/chat`。页面显示真实生成方式、模型名称、资料引用编号与来源链接，网络失败提示重试。固定回答函数仍保留在原模块以便比较，但正式界面不调用它。
2. 提问过程中禁用提交，关闭导游取消前端等待并隔离迟到响应；停止朗读不再错误取消模型请求。修复旧语音取消事件覆盖新请求状态的问题。
3. 近景与景点介绍访问会写入同一匿名会话的真实足迹。`nantianmen` 映射为后端 `nantian`；桃花源、东天门、五岳独尊尚不是后端独立节点，不伪造访问记录，其问答保留文本景点上下文。
4. 修复全局 hidden 属性被组件 display 样式覆盖的问题，避免南天门近景错误显示桃花源索道按钮。原“史”入口加入同源知识库的7条历史资料及来源。诗词保留原卡片、解析和白话按钮，用3首已有来源的诗替换未逐首核验的草稿；未核验作品可从 Git 基线恢复并审校后再增加。
5. 保留原创文学场景，明确标注“画卷情境”，将已收录景点的事实介绍与来源改为知识库数据，提供完整实景图与收藏/足迹入口。
6. 数字人原先按正弦时间周期持续张嘴，改为设备朗读实际边界事件驱动；不支持边界事件时不编造嘴部运动。它仍不是音素级口型，统一服务端语音及音频振幅口型属于后续开发。
7. 修复嵌入贴图通过 Blob URL 加载时被 CSP 阻断导致人物全白的问题；保持脚本仅同源，允许同源模型创建的 Blob 贴图读取，不开放外部脚本或模型服务密钥给浏览器。
8. 数字人动作按钮仅在相应动画实际加载后启用。关闭导游停止渲染；模型和缆车按需加载。手机布局改为短人物区与独立可滚动问答区，避免人物占据过多输入空间。
9. 完整导览主站 `/` 保留已上线验证的16处景点、20张署名实景、四线路交通分段、五章任务、收藏、足迹、云视觉与来源约束问答。新增入口“画卷”，两个界面共享后端与会话。
10. 删除 Git 跟踪中的 `node_modules/`、`dist/`，文件由锁文件和构建生成；原素材及模型仍保留。修复锁文件中 source-map-js 的高危依赖问题，npm audit 复查无漏洞。
