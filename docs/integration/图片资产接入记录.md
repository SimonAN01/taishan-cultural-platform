## 清单与复现

- `src/image-assets.json`：每张原文件名、SHA256、尺寸、透明状态、裁剪范围、网页路径与实际景点关联。
- `public/image-assets/`：57个已生成的WebP文件，源代码构建可直接使用。
- `scripts/import_image_assets.py`：从原ZIP复现网页资源，识别旧ZIP的中文文件名编码，避免同编号的背景与主体相互覆盖。

复现命令：

```sh
taishan/.venv/bin/python scripts/import_image_assets.py /绝对路径/图片资产.zip
npm run build
```

处理仅去除完全透明的外边缘并缩放、编码；不合成或臆造新的建筑，不对实际不透明的图片自动抠图。

## 发现与处理

`H-BG-15`文件命名为岱庙环境，画面却是亭台主体，本版作为“亭台点景”展示，不作为岱庙实景。`H-ND-16`虽然命名透明主体，实际是RGB全景，按全景保留。北天门、后石坞各有同编号的背景和主体，使用不同内部标识，两个文件均保留。
